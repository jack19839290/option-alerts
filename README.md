# 選擇權警示

目前版本：`0.10.0`

0.10.0 新增股票層級自動追蹤：全部標的移轉為180～360天的PUT、第二門檻年化至少10%、兩階段未平倉嚴格大於500。自動新增到期日並刪除已出範圍且通過身分核對的行情分頁；歷史保留。新版輸入頁為 `AutoIndex.html`，使用與部署步驟見 [UPGRADE_0.10.md](UPGRADE_0.10.md)。

0.9.1 修正收盤通知超過單一儲存格 50,000 字元而中斷：通知分段儲存並完整讀回，保留舊通知格式與歷史。升級請見 [UPGRADE_0.9.1.md](UPGRADE_0.9.1.md)。

0.9.0 新增獨立「波動率趨勢」收盤紀錄，保存 10Δ IV、25Δ IV、ATM IV 與兩種差值。使用與升級說明見 [VOLATILITY_TRENDS.md](VOLATILITY_TRENDS.md)。

以 Google Sheets 作為操作介面，GitHub Actions 透過 `yfinance` 讀取 Yahoo Finance 選擇權鏈，計算 Greeks 與賣出權利金年化報酬率，再把結果寫回試算表。Email 由綁定試算表的 Apps Script 寄出。

## 已實作功能

- 一個「股票＋到期日」對應一張期權鍊工作表，新版只顯示PUT與其履約價。
- 股票層級自動維持180～360天的所有可用到期日，新增、移除與條件套用由系統處理。
- 可設定兩組互相獨立的 Delta、Bid–Ask Spread、年化報酬率與未平倉量條件；每組已設定條件採 AND 邏輯。
- 新版輸入網頁只需股票與條件；已有標的會帶出共用設定。既有逐日期輸入介面保留作歷史相容來源，轉換後禁止由舊介面修改自動清單。
- 每日收盤 Email 依股票代號及到期日排序，沒有符合合約的股票／到期日不顯示空表格；全部為 0 筆時仍寄出簡短通知。
- Delta 條件實際比較 `|Delta|` 絕對值；Delta、Spread 與年化報酬率可選擇 `≥` 或 `≤`，未平倉量採嚴格大於設定口數。
- `Spread% = (Ask − Bid) ÷ Mid`；表單輸入 `10` 代表 10%。Bid、Ask 或 Mid 無效時，Spread 條件視為資料不足。
- 賣出試算價只使用有效 Bid；Bid 無效時不以 Last 代替，也不計算年化報酬率。
- PUT 年化報酬率為 `Bid ÷ 履約價 ÷ DTE × 365`。
- CALL 年化報酬率為 `Bid ÷ 持股成本 ÷ DTE × 365`；未填持股成本時留白。
- Delta、Gamma、Theta（每日）與 Vega（每 1% IV）由 Black-Scholes-Merton 模型估算，期權鍊依此順序顯示，最後再列出 `|Delta|`。
- Yahoo 的 `trailingAnnualDividendYield` 與 `dividendYield` 採各自單位正規化；不合理的股息率不會直接帶入 Greeks。
- 無風險利率優先讀取 Yahoo `^IRX` 的即時 `lastPrice`，其次採最近交易日 `Close`；兩者都失敗才使用設定中的備援值並在資料狀態標示。
- 第一門檻每天正式收盤寄出全部符合項目，包含 0 筆通知，並與上一個有效收盤比較標示「今日新增」。
- 第二門檻在首次符合時即時通知；同一輪多個合約合併，持續符合不重複寄送，但警示紀錄會保留該時間點所有符合項目。
- Email 列出 CALL／PUT、履約價、標的股價、Bid、Spread、Delta、年化報酬率、未平倉量與 DTE，不再列出 Gamma、Theta、Vega。
- 連續兩次有效不符合後才重新啟用該合約的通知，降低邊界值反覆寄信。
- 第一門檻條件變更會重建收盤比較基準；第二門檻條件變更後，當下符合項目會立即通知。
- Apps Script 在美股股票期權開盤、盤中每個整點與收盤各啟動一次；Python 端使用 CBOE 股票期權交易日曆判斷假日與提早收盤。
- 每次正式收盤更新會在「收盤Delta趨勢」保存PUT的 `|Delta|` 0.10、0.15、0.20 最接近但不超過目標的合約；既有CALL歷史保留。
- 每次正式收盤也會在獨立「波動率趨勢」保存同到期日、同類型的 10Δ IV、25Δ IV、ATM IV、10Δ − 25Δ 與 10Δ − ATM；資料不足時保留原因，不外推。
- 「收盤Delta趨勢」另存標的快照價減履約價的帶正負價差與價差率；升級時會補算既有可用歷史列。
- 收盤趨勢採每日唯一快照，不由手動更新寫入；無符合合約、Greeks 不足或抓取失敗也保留狀態列，避免缺資料被誤認為 0。
- 盤外不會自動寫入期權鍊；可從「選擇權警示 → 立即手動更新」，或勾選控制台 `H7`，隨時強制更新。
- GitHub 金鑰保存在 Apps Script 個人屬性，不寫入試算表；預設採 90 天有效期，並於到期前 7 天寄信提醒。
- 更新要求第一次失敗會立即寄信；持續失敗期間每 24 小時最多提醒一次，恢復時再通知一次。
- 遇到 Yahoo 流量限制時採 15／30／60 分鐘退避，不繞過限制。
- 通知改用逐筆狀態佇列，可查到待寄、寄送中、已寄與失敗重試；期權鍊採先寫入新版再清除舊尾列，降低中斷後整張空白的風險。
- 「警示紀錄」最上方會顯示每個期權鍊最新成功快照中的所有第一、第二門檻符合項目，不必等到寄信才出現；下方仍保留可由通知佇列重建的 Email 歷史。
- 刪除「警示紀錄」資料列後，下一次資料更新或執行「重建警示紀錄」會補回目前符合項目與可追溯的寄信紀錄；0 筆與資料不完整事件也會保留。
- 可從「選擇權警示 → 重建警示紀錄」立即補回被刪除的可追溯紀錄，不必等待下一次自動處理。
- 收盤門檻歷史每次執行只讀取一次，並對 Google Sheets API `429` 短暫限流自動等待後重試。
- 部分成功不會冒充完整成功；收盤會逐掃描記錄完成狀態並重試失敗項目。正式收盤失敗後，同一美東交易日晚間的手動更新可補建收盤快照，並標示「延後補抓」。市場行事曆無法確認時會明確停止自動警示。

## 重要限制

- `yfinance` 是非官方 Yahoo Finance 介面，資料可能延遲、缺漏、變更或暫時無法取得，不應視為交易所即時行情。
- 一般工作表時間依「設定 → 顯示時區」顯示，預設為 `Asia/Taipei`；欄位名稱含 `(UTC)` 的系統稽核時間仍使用 UTC。
- Yahoo 未平倉量可能不是即時更新；系統只使用當次實際取得的數值。
- Greeks 是模型估算，不是 Yahoo 原始欄位；輸入包含標的價格、Yahoo IV、利率、股息殖利率與剩餘時間。
- 年化報酬率未扣除手續費、稅金、股息、融資成本、滑價及提前指派風險。
- 自動更新與 Email 需要先完成 [GITHUB_ACTIONS.md](GITHUB_ACTIONS.md) 的 GitHub Secrets、試算表分享與 Apps Script 授權。
- 本工具只提供資料整理與條件通知，不會下單，也不構成投資建議。
